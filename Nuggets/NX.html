Graph Theory with NetworkX

Assignment (10 marks) · Introduction, getting started, and topic-wise tasks

1. What is NetworkX?

NetworkX is a free Python package for creating, manipulating and studying graphs. It has ready-made graph families (complete, cycle, Petersen, …), and algorithms for connectivity, colouring, matching, flows, planarity and more. It also converts graphs to matrices (via NumPy) and draws them (via Matplotlib). In this assignment you will use it as a laboratory to test the theorems you study in class.

Your first graph

import networkx as nx
import matplotlib.pyplot as plt

G = nx.Graph()                       # empty undirected graph
G.add_node(1)                        # add a vertex
G.add_nodes_from([2, 3, 4])          # add several vertices
G.add_edge(1, 2)                     # add an edge
G.add_edges_from([(2, 3), (3, 4), (4, 1), (1, 3)])

print(G.nodes)                       # [1, 2, 3, 4]
print(G.edges)                       # list of edges
print(G.number_of_nodes(), G.number_of_edges())
print(dict(G.degree()))              # degree of each vertex

nx.draw(G, with_labels=True, node_color="lightblue", node_size=700)
plt.show()

4. Topic-wise tasks

The “Useful” line lists functions to explore; you must read their documentation yourself.

1Degree sequence

  1. A. Compute the degree sequence (non-increasing) of K5, C6, the Petersen graph and a star K1,6.
  2. B. Verify the handshaking lemma on 10 random graphs. Test whether the sequences (3,3,2,2,1,1), (4,4,3,1,0) and (3,3,3,1) are graphical, and realise a graphical one using Havel–Hakimi.
  3. C. Find two non-isomorphic graphs with the same degree sequence and draw them.
Useful: G.degree(), nx.is_graphical, nx.havel_hakimi_graph, nx.is_isomorphic

2Connected graphs

  1. A. Build a graph with 3 components; list the components and their sizes.
  2. B. Verify: a graph with n vertices and fewer than n−1 edges is disconnected; a connected graph has at least n−1 edges.
  3. C. For n = 50, estimate the probability that G(n,p) is connected for several p (100 trials each) and compare with the threshold p ≈ ln n / n. Plot your result.
Useful: nx.is_connected, nx.connected_components, nx.gnp_random_graph

3Paley graphs / Cayley graphs

  1. A. Generate Paley graphs for primes p = 5, 13, 17, 29 (p ≡ 1 mod 4); draw at least two. Build the Cayley graph of Zn with connection set S = {±1, ±3}, both by hand and with nx.circulant_graph.
  2. B. Verify that the Paley graph is regular of degree (p−1)/2, and that every pair of adjacent (non-adjacent) vertices has the same number of common neighbours (strongly regular).
  3. C. Check whether the Paley graph is isomorphic to its complement. Build a Cayley graph of a non-cyclic group (e.g. Z2×Z2×Z2) and identify it.
Useful: nx.paley_graph (returns a directed graph; use .to_undirected()), nx.circulant_graph, nx.common_neighbors

4Trees

  1. A. Generate 5 random trees on 8 vertices and confirm each is a tree. Find a spanning tree of the Petersen graph.
  2. B. Verify: a tree on n vertices has n−1 edges; it has at least two leaves; adding any edge creates exactly one cycle. Convert trees to Prüfer sequences and back.
  3. C. Verify Cayley's formula (nn−2 labelled trees) for n ≤ 6 by counting spanning trees of Kn via the determinant of a Laplacian cofactor.
Useful: nx.is_tree, nx.random_labeled_tree, nx.minimum_spanning_tree, nx.to_prufer_sequence, nx.from_prufer_sequence

5Hamiltonian graphs

  1. A. Write your own backtracking (or itertools.permutations) function that finds a Hamiltonian cycle if one exists.
  2. B. Test it on Cn, Kn, the cube Q3, K3,4, the Petersen graph and the dodecahedral graph. Verify Dirac's condition (δ ≥ n/2 ⇒ Hamiltonian) on random graphs.
  3. C. Find a non-Hamiltonian graph that violates Dirac's condition but still has a Hamiltonian path; explain why the converse of Dirac fails.
Useful: nx.petersen_graph, nx.dodecahedral_graph, nx.hypercube_graph. (NetworkX has no general Hamiltonian test.)

6Eulerian graphs

  1. A. Model the Königsberg bridges as a MultiGraph and show it has no Euler circuit or path.
  2. B. For 15 graphs (built-in and random connected ones), verify: Eulerian ⇔ connected with all degrees even; semi-Eulerian ⇔ exactly two odd vertices.
  3. C. Given a connected graph with 2k odd vertices, add the minimum number of edges to make it Eulerian (pair up odd vertices) and print the Euler circuit.
Useful: nx.MultiGraph, nx.is_eulerian, nx.is_semieulerian, nx.eulerian_circuit, nx.eulerian_path

7Self-complementary graphs

  1. A. Show that P4 and C5 are self-complementary using nx.complement and nx.is_isomorphic.
  2. B. Using the graph atlas (all graphs up to 7 vertices), list all self-complementary graphs for each n ≤ 7. Verify that they exist only when n ≡ 0 or 1 (mod 4) and have n(n−1)/4 edges.
  3. C. Count them for each n and compare with your presentation; draw the n = 5 ones.
Useful: nx.complement, nx.is_isomorphic, nx.graph_atlas_g()

8Automorphism group of a graph

  1. A. Write a function that lists all automorphisms of a small graph (as vertex permutations) using the isomorphism matcher on G with itself.
  2. B. Compute |Aut(G)| for K4, C5, C6, P5, K1,4, K2,3 and the Petersen graph (expected 120). Match with the known groups (Sn, Dn, …).
  3. C. Compute the orbits of vertices; decide which graphs above are vertex-transitive.
Useful: from networkx.algorithms.isomorphism import GraphMatcher; GraphMatcher(G,G).isomorphisms_iter()

9Planar graphs

  1. A. Test planarity of K4, K5, K3,3, the Petersen graph, the cube and the dodecahedron; draw the planar ones with a planar layout.
  2. B. For planar graphs verify Euler's formula V − E + F = 2 (count faces from the embedding) and the bound E ≤ 3V − 6.
  3. C. Show that deleting one edge of K5 gives a planar graph; show that K3,3 contains no triangle, so E ≤ 2V − 4 fails, proving non-planarity.
Useful: nx.check_planarity (returns (is_planar, embedding)), nx.draw_planar, embedding.traverse_face

10Coloring

  1. A. Colour the Petersen graph with the greedy algorithm using at least three different strategies; compare the number of colours used.
  2. B. Write a brute-force function to find the chromatic number χ(G) of a small graph. Verify χ(Ceven)=2, χ(Codd)=3, χ(Kn)=n, χ(Petersen)=3 and Brooks' bound.
  3. C. Draw a coloured graph where greedy uses more than χ(G) colours (change the vertex order).
Useful: nx.coloring.greedy_color(G, strategy="largest_first"), strategies smallest_last, DSATUR, random_sequential; nx.draw(G, node_color=...)

11Vertex connectivity and edge connectivity

  1. A. Compute κ(G) and λ(G) for Kn, Cn, Km,n, the Petersen graph and the cube.
  2. B. Verify Whitney's inequality κ ≤ λ ≤ δ on 30 random connected graphs.
  3. C. Find a minimum vertex cut and minimum edge cut, remove them, and show the graph becomes disconnected. Construct a graph with κ < λ < δ.
Useful: nx.node_connectivity, nx.edge_connectivity, nx.minimum_node_cut, nx.minimum_edge_cut

12Bipartite graphs

  1. A. Build K3,4 and a random bipartite graph; obtain the two parts and draw with the parts in two columns.
  2. B. Verify: G is bipartite ⇔ it has no odd cycle. Test on cycles, trees, hypercubes, the Petersen graph and random graphs (use nx.cycle_basis to inspect cycle lengths).
  3. C. Verify that the spectrum of a bipartite graph is symmetric about 0; check it fails for a non-bipartite graph.
Useful: nx.is_bipartite, nx.bipartite.sets, nx.bipartite.color, nx.bipartite.random_graph, nx.bipartite_layout

13Independent sets

  1. A. Find a maximal independent set of the Petersen graph.
  2. B. Compute the independence number α(G) exactly (via maximum cliques of the complement) for Cn, Kn, Km,n, the Petersen graph and the cube. Verify α(G) = ω(complement of G).
  3. C. Compare a randomly obtained maximal independent set with the maximum one; run 100 trials and report how often you get a maximum set.
Useful: nx.maximal_independent_set, nx.find_cliques, nx.complement, nx.graph_clique_number (or take max over find_cliques)

14Vertex covering and edge covering

  1. A. Find a minimum edge cover of a graph and an approximate vertex cover. Check that your sets really cover.
  2. B. Compute the vertex cover number β by brute force. Verify Gallai's identities α + β = n and α′ + β′ = n (for graphs with no isolated vertex), where α′ is the matching number and β′ the edge cover number.
  3. C. Check König's theorem (β = α′) on bipartite graphs, and find a non-bipartite graph where it fails.
Useful: nx.min_edge_cover, nx.algorithms.approximation.min_weighted_vertex_cover, nx.max_weight_matching

15Network flow problems

  1. A. Build a directed network with source s, sink t and at least 7 edges with capacities; draw it with capacity labels.
  2. B. Compute the maximum flow and a minimum cut. Verify max-flow = min-cut capacity and flow conservation at each internal vertex.
  3. C. Model a bipartite matching problem as a flow network (unit capacities) and solve it with maximum_flow. Optionally add costs and use max_flow_min_cost.
Useful: nx.DiGraph with capacity=, nx.maximum_flow, nx.minimum_cut, nx.max_flow_min_cost, nx.get_edge_attributes

16Adjacency matrix

  1. A. Obtain the adjacency matrix of K4, C5, P4 and the Petersen graph; rebuild a graph from a given matrix.
  2. B. Verify: (Ak)ij = number of walks of length k from i to j; trace(A3) = 6 × (number of triangles); row sums = degrees.
  3. C. Compute the eigenvalues of the Petersen graph (3, 1, −2 with multiplicities 1, 5, 4) and of Kn; check that the largest eigenvalue lies between average and maximum degree.
Useful: nx.to_numpy_array, nx.from_numpy_array, nx.adjacency_matrix, numpy.linalg.eigvalsh, nx.triangles

17Laplacian matrix

  1. A. Compute L = D − A for several graphs and check that it equals D − A built manually.
  2. B. Verify: L is positive semidefinite; the multiplicity of eigenvalue 0 equals the number of components; every row sums to 0; matrix-tree theorem (any cofactor = number of spanning trees).
  3. C. Compute the algebraic connectivity of paths, cycles and Kn for n = 4…10, plot against n, and relate to vertex connectivity (a(G) ≤ κ(G) for non-complete G).
Useful: nx.laplacian_matrix(G).toarray(), nx.laplacian_spectrum, nx.algebraic_connectivity (needs SciPy)

18Distance matrix

  1. A. Compute the distance matrix of P5, C6, K3,3 and the Petersen graph.
  2. B. From the matrix read off eccentricities, radius, diameter and centre; verify rad ≤ diam ≤ 2·rad on 20 random connected graphs. Compare with the NetworkX functions.
  3. C. Compute the Wiener index (sum of distances over unordered pairs). Among all trees on 8 vertices, find the ones with minimum and maximum Wiener index (hint: star and path).
Useful: nx.floyd_warshall_numpy, nx.shortest_path_length, nx.eccentricity, nx.diameter, nx.radius, nx.center, nx.wiener_index

19Matching

  1. A. Find a maximum matching in the Petersen graph, C7 and a random graph; draw matched edges in a different colour.
  2. B. Verify: a perfect matching exists in K2n and even cycles but not odd cycles; for a bipartite graph check Hall's condition (|N(S)| ≥ |S| for all subsets S) against the result of the algorithm.
  3. C. Solve a small job-assignment problem (4 workers, 4 jobs with weights) with a maximum-weight matching; also test Tutte's/Petersen's theorem: every bridgeless cubic graph has a perfect matching.
Useful: nx.max_weight_matching(G, maxcardinality=True), nx.is_perfect_matching, nx.is_maximal_matching, nx.bipartite.maximum_matching, nx.min_weight_matching

  • Use small examples first; draw them before running heavy tests.
  • Always print results with a label, e.g. print("kappa(Petersen) =", nx.node_connectivity(P)).
  • Use seed= in random functions so that your results can be reproduced.
  • If a function does not exist in NetworkX (for example a Hamiltonian test), write your own and explain the logic in comments.
  • You may consult the official documentation, but your explanations must be in your own words.
