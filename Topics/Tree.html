Section 1

Introduction

Definition

A tree is a graph $T=(V,E)$ that is connected and contains no cycles (i.e. is acyclic). Throughout, $n=|V|$ denotes the number of vertices.

Section 2

A Few Immediate Observations

These facts follow directly from the definition (connected + acyclic) and are used repeatedly later.

Lemma 0

Every tree $T$ with $n \ge 2$ vertices has at least one vertex of degree $1$ (a leaf, or pendant vertex).

Proof. Since $T$ is finite, it has a path of maximum length; write it as $v_0v_1\cdots v_k$. We claim $\deg(v_0)=1$.

Suppose not: then $v_0$ has some neighbour $u \ne v_1$. There are two possibilities.

• If $u$ does not lie on the path, then $u, v_0, v_1, \dots, v_k$ is a longer path — contradicting maximality.

• If $u = v_i$ for some $i \ge 2$, then $v_0v_1\cdots v_i v_0$ is a cycle — contradicting that $T$ is acyclic.

Both cases are impossible, so $\deg(v_0)=1$: the endpoint of a longest path is always a leaf.

∎

Lemma 1

A tree $T$ with $n \ge 3$ vertices contains a vertex of degree at least $2$.

Proof. Since $T$ is connected and $n\ge 2$, no vertex can be isolated, so every vertex has degree $\ge 1$.

Suppose, for contradiction, that every vertex has degree exactly $1$. Pick any vertex $v_0$; it has a unique neighbour $v_1$, and since $\deg(v_1)=1$ as well, $v_1$'s only edge is the one back to $v_0$.

Now take any third vertex $w$ (it exists, since $n\ge 3$). By connectivity there is a path from $v_0$ to $w$. Its first step must go to $v_0$'s only neighbour, $v_1$. But $v_1$ has no other edge to continue on, so the path cannot proceed any further unless $w=v_1$. Since $w$ was an arbitrary third vertex distinct from $v_0,v_1$, this is a contradiction: $w$ cannot be reached.

So not every vertex can have degree exactly $1$; since every degree is $\ge 1$, some vertex must have degree $\ge 2$.

∎

Lemma 2

If a tree $T$ has a vertex $v$ of degree $k \ge 2$, then $T$ has at least $k$ pendant vertices (leaves).

Step 1: removing $v$ leaves exactly $k$ components. Let $u_1,\dots,u_k$ be the neighbours of $v$. Since $T$ is connected, deleting $v$ leaves each remaining vertex still reachable from some $u_i$, so every component of $T-v$ contains at least one $u_i$. If some component contained two of the $u_i$'s, say $u_i$ and $u_j$, then joining a $u_i$–$u_j$ path inside that component with the two edges $vu_i$ and $vu_j$ would produce a cycle through $v$ — contradicting acyclicity. So each of the $k$ components of $T-v$ contains exactly one $u_i$; there are exactly $k$ components, call them $T_1,\dots,T_k$ (with $u_i \in T_i$).

Step 2: each $T_i$ contributes a leaf of $T$. Fix $i$. If $T_i$ consists of the single vertex $u_i$, then in $T$, $u_i$'s only neighbour is $v$ itself, so $\deg_T(u_i)=1$ — i.e. $u_i$ is a leaf of $T$. Otherwise $T_i$ has $\ge 2$ vertices; being connected and acyclic (a subgraph of the acyclic graph $T$), $T_i$ is itself a tree, so by Lemma 0 it has some leaf $\ell_i \ne u_i$ possible, or possibly $\ell_i = u_i$. In either case $\ell_i$'s only neighbour inside $T_i$ is one other vertex of $T_i$, and $\ell_i$ is not adjacent to $v$ (only $u_i$ is, among vertices of $T_i$, and if $\ell_i \ne u_i$ it has no edge to $v$). So $\deg_T(\ell_i) = 1$: $\ell_i$ is a leaf of $T$.

Step 3: these leaves are distinct. The leaf found in branch $T_i$ lies in $T_i$, and the sets $T_1,\dots,T_k$ are pairwise disjoint (different components of $T-v$). So the $k$ leaves $\ell_1,\dots,\ell_k$ are $k$ distinct leaves of $T$. Hence $T$ has at least $k$ leaves.

∎

Lemma 3

Every tree $T$ is bipartite: its vertex set can be split into two classes $A,B$ so that every edge of $T$ joins a vertex of $A$ to a vertex of $B$ (equivalently, no edge has both endpoints in $A$, and none has both endpoints in $B$).

Proof 1 — via the even-cycle criterion

A standard characterization of bipartite graphs is:

A graph is bipartite if and only if it contains no cycle of odd length.

Assume $G$ is connected with no odd cycle (the disconnected case follows by treating each component separately). Fix a root $r$ and let $A,B$ be the sets of vertices at even, respectively odd, distance from $r$ (distance = length of a shortest $r$–$v$ path).

Suppose some edge $uw$ had both endpoints in the same class, i.e. $d(r,u)$ and $d(r,w)$ have the same parity. Take shortest paths $P_u$ from $r$ to $u$ and $P_w$ from $r$ to $w$, and let $z$ be the last vertex they have in common. The two sub-paths from $z$ to $u$ and from $z$ to $w$ have lengths of the same parity (since $d(z,u)-d(z,w) = d(r,u)-d(r,w)$ is even), so combining them with the edge $uw$ produces a closed walk of odd total length, which contains an odd cycle — contradicting our assumption. So every edge joins $A$ to $B$: $G$ is bipartite.

∎

Now apply this to a tree $T$: by definition (statement (1) of Section 3), $T$ has no cycles at all — so in particular it has no cycle of odd length, vacuously. By the criterion above, $T$ is bipartite.

∎

Proof 2 — directly, by distance parity from a root

Fix any vertex $r$ of $T$ as a root. Since $T$ is a tree, every vertex $v$ has a unique path from $r$ (statement (6) of Section 3), so its distance $d(r,v)$ — the length of that path — is well defined. Let

$A=\{v : d(r,v) \text{ is even}\}, \qquad B=\{v : d(r,v) \text{ is odd}\}.$

Let $uw$ be any edge of $T$. Removing the edge $uw$ from $T$ splits it into two components (Lemma 2's argument, with $k=2$ here restricted to this single edge); say $w$ lies on the far side from $r$. Then the unique $r$–$w$ path must pass through $u$ and use the edge $uw$ as its last step (any $r$–$w$ path not using edge $uw$ together with the edge $uw$ would create a second $r$-to-$w$ route, contradicting uniqueness). Hence $d(r,w) = d(r,u)+1$.

So the two endpoints of every edge have distances from $r$ that differ by exactly $1$ — one even, one odd. Thus every edge joins a vertex of $A$ to a vertex of $B$, and $\{A,B\}$ is a bipartition of $T$.

∎

Section 3

Equivalent Conditions for a Tree

Let $T=(V,E)$ be a finite graph with $n=|V|\ge 1$ vertices. The following six statements about $T$ are logically equivalent.

  1. (1) $T$ is a tree: it is connected and acyclic.
  2. (2) $T$ is connected and has exactly $n-1$ edges.
  3. (3) $T$ is acyclic and has exactly $n-1$ edges.
  4. (4) $T$ is acyclic, and adding any single missing edge to $T$ creates exactly one cycle. (edge-maximal acyclic graph)
  5. (5) $T$ is connected, and every edge of $T$ is a bridge (deleting it disconnects $T$). (minimally connected graph)
  6. (6) Every pair of distinct vertices of $T$ is joined by a unique path.
Why a cycle of implications is enough. To show six statements are pairwise equivalent, it suffices to prove one directed cycle through all of them — here $(1)\Rightarrow(2)\Rightarrow(3)\Rightarrow(4)\Rightarrow(5)\Rightarrow(6)\Rightarrow(1)$. Since implication is transitive, following the arrows around lets you get from any statement to any other, in either direction. That single cycle therefore proves all $\binom{6}{2}=15$ pairwise equivalences at once.

The proof chain

(1) ⇒ (2) A tree has $n-1$ edges

Claim. If $T$ is connected and acyclic, it has exactly $n-1$ edges.

Proof (induction on $n$). If $n=1$, $T$ is a single vertex with $0=n-1$ edges.

Assume the claim holds for all trees with fewer than $n$ vertices, and let $T$ be a tree with $n\ge 2$ vertices. By Lemma 0, $T$ has a leaf $v$. Let $T^{\prime} = T - v$ (delete $v$ and its one incident edge).

$T^{\prime}$ is still acyclic (a subgraph of an acyclic graph is acyclic) and still connected: since $v$ had degree $1$, it lay on no path between any two other vertices, so all such paths survive intact in $T^{\prime}$. Thus $T^{\prime}$ is a tree on $n-1$ vertices, and by the induction hypothesis it has $(n-1)-1 = n-2$ edges.

$T$ has exactly one more edge than $T^{\prime}$ (the edge at $v$), so $T$ has $n-2+1 = n-1$ edges.

∎

Corollary (used below). Every connected graph on $n$ vertices has at least $n-1$ edges.

If a connected graph $T$ contains a cycle, pick an edge $e$ on that cycle. Deleting $e$ keeps $T$ connected, because the two endpoints of $e$ remain joined via the rest of the cycle, and no other pair of vertices loses its only connection. Repeat this on any remaining cycle. Since the edge count strictly decreases each time, the process must stop — at a connected, acyclic spanning subgraph $T^{\prime}$, i.e. a spanning tree on the same $n$ vertices.

By (1)⇒(2) above, $T^{\prime}$ has $n-1$ edges. Since $T^{\prime}$ is obtained from $T$ only by deleting edges, $|E(T)| \ge |E(T^{\prime})| = n-1$.

∎

(2) ⇒ (3) Connected + $n-1$ edges forces no cycles

Claim. If $T$ is connected with exactly $n-1$ edges, then $T$ is acyclic.

Proof. Suppose, for contradiction, that $T$ has a cycle. Pick an edge $e$ lying on it. As in the Corollary above, $T-e$ is still connected, now with $n-2$ edges.

But the Corollary says every connected graph on $n$ vertices needs at least $n-1$ edges — and $n-2 < n-1$. Contradiction.

So $T$ has no cycle: $T$ is acyclic. Together with the hypothesis of $n-1$ edges, this is exactly statement (3).

∎

(3) ⇒ (4) Acyclic + $n-1$ edges is edge-maximal

Claim. If $T$ is acyclic with exactly $n-1$ edges, then adding any missing edge creates exactly one cycle.

Step 1 — $T$ must be connected. If a forest (acyclic graph) has $n$ vertices split into $c$ connected components, each component is itself a tree, so by (1)⇒(2) it has (its own vertex count $-1$) edges. Summing over all $c$ components gives a total of $n-c$ edges. Since $T$ has $n-1$ edges, we get $c=1$: $T$ is connected. Being connected and acyclic, $T$ is a tree.

Step 2 — Any two vertices have a unique path. Connectivity gives at least one path between any $u,v$. For at most one: if $u,v$ had two distinct paths $P_1 \ne P_2$, follow them from $u$ until they first diverge, and note they must later reconverge (both end at $v$); the two distinct routes between the divergence and reconvergence points form a cycle — contradicting acyclicity. So the path between any $u,v$ is unique; call it $P_{uv}$.

Step 3 — Adding an edge creates exactly one cycle. Let $uv$ be any pair not already joined by an edge. Then $P_{uv}$ together with the new edge $uv$ forms a cycle in $T+uv$. If $T+uv$ had a second cycle $C$, then $C$ cannot avoid the new edge (otherwise $C \subseteq T$, contradicting $T$ acyclic); removing $uv$ from $C$ leaves a $u$–$v$ path inside $T$, which must equal $P_{uv}$ by uniqueness. So $C$ is the same cycle as $P_{uv}+uv$. Hence exactly one cycle is created.

∎

(4) ⇒ (5) Edge-maximal acyclic is minimally connected

Claim. If $T$ is acyclic and every missing edge would create a cycle, then $T$ is connected and every edge of $T$ is a bridge.

Connectedness. Suppose $T$ were disconnected, with $u$ and $v$ in different components. The edge $uv$ is missing, but adding it cannot create a cycle: a cycle through $uv$ would require another $u$–$v$ path already inside $T$, impossible since $u$ and $v$ lie in different components. This contradicts the hypothesis that adding any missing edge creates a cycle. So $T$ is connected — hence, with acyclicity, $T$ is a tree.

Every edge is a bridge. Let $e=uv \in E(T)$. Because $T$ is acyclic, $e$ is the only path from $u$ to $v$: any other route from $u$ to $v$ avoiding $e$ would, together with $e$, form a cycle. So once $e$ is deleted, $u$ and $v$ have no remaining path — $T-e$ is disconnected, i.e. $e$ is a bridge. As $e$ was arbitrary, every edge of $T$ is a bridge.

∎

(5) ⇒ (6) Minimally connected gives unique paths

Claim. If $T$ is connected and every edge is a bridge, then every pair of vertices has a unique connecting path.

Existence. Immediate from connectivity: some path joins any $u,v$.

Uniqueness. Suppose some pair $u,v$ had two distinct paths $P_1\ne P_2$. As in the argument above, two distinct paths between the same two vertices always force a cycle somewhere in the graph (they diverge and later reconverge, and the two routes in between form a cycle). So $T$ would contain a cycle $C$.

But no edge lying on a cycle can be a bridge: deleting an edge of $C$ still leaves its two endpoints connected via the rest of $C$, so the graph stays connected. This contradicts the hypothesis that every edge of $T$ is a bridge.

So no two distinct paths can exist between any pair of vertices: the path is unique.

∎

(6) ⇒ (1) Unique paths give a tree

Claim. If every pair of vertices is joined by exactly one path, then $T$ is connected and acyclic.

Connected. A path exists between every pair of vertices, in particular — so $T$ is connected.

Acyclic. Suppose $T$ had a cycle $v_0v_1\cdots v_kv_0$ (with $k \ge 2$). Then $v_0$ and $v_1$ are joined by two different paths: the direct edge $v_0v_1$, and the longer route $v_0, v_k, v_{k-1}, \dots, v_1$ around the rest of the cycle. This contradicts the assumed uniqueness of the $v_0$–$v_1$ path.

So $T$ has no cycle. Being both connected and acyclic, $T$ is a tree — statement (1).

∎

The chain $(1)\Rightarrow(2)\Rightarrow(3)\Rightarrow(4)\Rightarrow(5)\Rightarrow(6)\Rightarrow(1)$ is now complete, so all six statements are pairwise equivalent. $\blacksquare$
Section 4

Degree Sequences of Trees

Theorem. A list of positive integers $d_1,d_2,\dots,d_n$ (with $n\ge2$) is the degree sequence of some tree on $n$ vertices if and only if

$d_i \ge 1$ for every $i$,  and  $\displaystyle\sum_{i=1}^n d_i = 2n-2$.

Necessity. If $T$ is a tree on $n$ vertices, it has $n-1$ edges by (1)⇒(2) of Section 3. Every edge contributes $1$ to the degree of each of its two endpoints, so $\sum_i \deg(v_i) = 2|E(T)| = 2(n-1)$. Every vertex has degree $\ge 1$ since $T$ is connected with $n\ge 2$.

Sufficiency (construction via Prüfer sequences). Given $d_1,\dots,d_n\ge 1$ with $\sum d_i = 2n-2$, build the list $S$ containing the label $i$ repeated exactly $d_i-1$ times, for each $i=1,\dots,n$. Since $\sum(d_i-1) = (2n-2)-n = n-2$, $S$ has exactly $n-2$ entries — a valid Prüfer sequence (Section 6). Decoding $S$ produces a tree in which vertex $i$ has degree exactly $1+(\text{occurrences of } i \text{ in } S) = 1+(d_i-1) = d_i$, realizing the prescribed sequence.

∎

Practice problems

1. Is $(3,1,1,1,2)$ the degree sequence of a tree on $5$ vertices?

Sum $=3+1+1+1+2=8=2(5)-2$, and every term is $\ge1$. Yes.

2. Is $(1,1,1,1,1,1)$ the degree sequence of a tree on $6$ vertices?

Sum $=6$, but we need $2(6)-2=10$. No — in fact six vertices all of degree $1$ cannot even form a connected graph once $n\ge3$ (Lemma 1).

3. Is $(4,2,2,1,1)$ the degree sequence of a tree on $5$ vertices?

Sum $=4+2+2+1+1=10$, but we need $2(5)-2=8$. No.

4. Is $(5,1,1,1,1,1)$ the degree sequence of a tree on $6$ vertices? If so, which tree?

Sum $=5+5=10=2(6)-2$, all $\ge1$. Yes — it is the star $K_{1,5}$, since the single vertex of degree $5$ must be adjacent to all other vertices.

Section 5

Counting Labelled Trees: Cayley's Formula

So far we compared trees up to isomorphism (Section 1). Now fix the vertex set to be $\{1,2,\dots,n\}$ and count labelled trees — trees on these specific, distinguishable vertices, where relabelling counts as a different tree unless the labelling is identical.

Cayley's Formula. The number of distinct labelled trees on $n\ge2$ vertices is

$$n^{\,n-2}.$$

$n^{n-2}$11316125129616807
This is OEIS A000272. Compare it with the non-isomorphic counts from Section 1 ($1,1,1,2,3,6,11,\dots$): there are $16$ labelled trees on $4$ vertices, but only $2$ shapes — every labelling of the path $P_4$ or the star $K_{1,3}$ falls into one of those two shapes.

Cayley's formula is most cleanly proved by exhibiting a bijection between labelled trees on $\{1,\dots,n\}$ and sequences of length $n-2$ over the alphabet $\{1,\dots,n\}$ — of which there are exactly $n^{n-2}$. This bijection is the Prüfer correspondence, developed next.

Section 6

Prüfer Sequences

The Prüfer sequence gives a two-way dictionary between labelled trees on $\{1,\dots,n\}$ and sequences of length $n-2$ over $\{1,\dots,n\}$.

Encoding: a tree → a sequence

While more than $2$ vertices remain:

  1. Find the smallest-labelled leaf in the current tree.
  2. Record the label of its unique neighbour.
  3. Delete that leaf and repeat.

After $n-2$ rounds exactly $2$ vertices remain; stop. The recorded labels, in order, form the Prüfer sequence.

Decoding: a sequence → a tree

Given $S=(s_1,\dots,s_{n-2})$ over $\{1,\dots,n\}$: give every label a "current degree", initialised to $1$ plus the number of times it occurs in $S$. Then repeatedly:

  1. Find the smallest-labelled vertex $\ell$ that currently has degree $1$ and hasn't yet been used as a leaf.
  2. Join $\ell$ to the next unused entry of $S$; reduce both of their current degrees by $1$.

Once $S$ is exhausted, exactly two vertices of current degree $1$ remain — join them with one final edge.

Key fact. In the tree produced, $\deg(v) = 1 + (\text{number of times } v \text{ appears in } S)$. The labels that never appear in $S$ are exactly the leaves. Since encoding and decoding undo each other, this is a bijection between labelled trees on $n$ vertices and sequences of length $n-2$ over $n$ symbols — and there are exactly $n^{n-2}$ of the latter, which is Cayley's formula.

Section 7

Spanning Trees

Definition. A spanning tree of a connected graph $G=(V,E)$ is a subgraph $T=(V,E')$, $E'\subseteq E$, that is itself a tree — it touches every vertex of $G$ while using only $|V|-1$ edges and containing no cycle.

Theorem. Every connected graph has a spanning tree.

Proof 1 — delete edges from cycles (top-down)

This is exactly the Corollary used in Section 3. If $G$ has a cycle, delete an edge from it: the two endpoints stay joined via the rest of the cycle, so the graph remains connected, now with one fewer edge. Repeat on any remaining cycle. Since the edge count strictly decreases and is bounded below, the process must terminate — at a connected, acyclic spanning subgraph, i.e. a spanning tree.

Proof 2 — add edges between components (bottom-up)

Start with all $n=|V|$ vertices of $G$ and no edges (so $n$ trivial components). Repeatedly pick any edge of $G$ whose two endpoints currently lie in different components, and add it, merging the two components into one. Stop when no such edge remains.

Acyclic. Every added edge joins two different, previously unconnected components, so it can never close a cycle (a cycle would need its endpoints already joined by some other path, i.e. already in the same component).

Connected at the end. If two vertices ended up in different components, then — since $G$ itself is connected — some edge of $G$ along a path between them would still cross between those two components, and the process wouldn't have stopped. So at termination everything is in one component.

Exactly $n-1$ edges. We start with $n$ components; each added edge merges two into one, decreasing the count by exactly $1$. Going from $n$ components to $1$ takes exactly $n-1$ additions.

Connected with $n-1$ edges — by Section 3, this is a tree, and by construction it spans every vertex of $G$.

∎

This "join two different components" rule is exactly the idea behind Kruskal's algorithm, and behind building a spanning tree via breadth-first or depth-first search.

Section 8

Classifying Trees by Diameter

Definition. The diameter of a tree $T$ is the greatest distance between any two of its vertices. Since paths in a tree are unique (statement (6), Section 3), this is the same as the number of edges in $T$'s longest path — and the two endpoints of a longest path are always leaves (a non-leaf endpoint could always be extended further, lengthening the path).

A tree of diameter $d$ needs at least $d+1$ vertices: the longest path itself already has $d+1$ vertices. Equality holds only for the path $P_{d+1}$, which is therefore the unique smallest tree of diameter $d$.

Reusing the catalogue of every non-isomorphic tree on $4$ to $7$ vertices from Section 1, here is every such tree sorted by its diameter. (Diameter $7$ needs at least $8$ vertices, so only the minimal example — the path $P_8$ — is shown; for $n\ge 8$ many more non-isomorphic shapes of diameter $7$ appear, just as branching created more shapes at each fixed diameter below.)

A pattern worth noticing: diameter $2$ is realized only by stars (exactly one shape per $n$); diameter $3$ only by the path $P_4$ or by double stars; and from diameter $4$ onward, branching gives genuinely more freedom — trees of diameter $4$ all have a single center vertex within distance $2$ of every other vertex, with at least two branches reaching all the way out to distance $2$ (this is the "radius vs. diameter" relationship: for even diameter $d$, the center is one vertex of eccentricity $d/2$; for odd diameter $d$, the center is a pair of adjacent vertices, each of eccentricity $(d+1)/2$).
