SECTION 1

Definition & Basic Examples

Formal Definition

An undirected simple graph G = (V, E) is connected if for every pair of distinct vertices u, v ∈ V, there exists a path starting at u and ending at v.

If a graph is not connected, it is disconnected, and its maximal connected subgraphs are called its connected components.

Examples of Connected Graphs:
  • Complete Graph (Kn): Direct edge between every pair of vertices.
  • Cycle Graph (Cn, n ≥ 3): A single continuous ring.
  • Tree (Tn): Connected acyclic graph with exactly n - 1 edges.
Non-Examples (Disconnected):
  • Empty Graph (K̄n, n ≥ 2): Vertices with zero edges.
  • Disjoint Union (K3 ∪ K2): Two isolated cliques with no path between them.

SECTION 3

Co-Connected Graphs: When Both X and Xc are Connected

The complement graph Xc has the same vertex set as X, but two vertices are adjacent in Xc if and only if they are not adjacent in X.

Key Theorem: Complement Connectivity

For any simple graph X, at least one of X or Xc is connected.

Proof: If X is disconnected, vertices in different components of X have direct edges between them in Xc. Vertices within the same component of X connect in Xc via any vertex from another component!

Diameter Bounds when both X and Xc are Connected

Suppose both X and Xc are connected (requires n ≥ 4):

  • Minimum Diameter: min diam = 2.
    If diam(X) = 1, then X ≅ Kn, which forces Xc to be completely disconnected (diam = ∞).
  • Maximum Diameter: max diam = 3.
    If diam(X) ≥ 4, then diam(Xc) ≤ 2. Thus, the maximum diameter for both X and Xc to remain connected simultaneously is 3 (e.g., P4).
Result: If both X and Xc are connected ⇒ 2 ≤ diam(X) ≤ 3 and 2 ≤ diam(Xc) ≤ 3

SECTION 4

Minimum Edges Required to Guarantee Connectivity

Question: What is the minimum number of edges required so that ANY graph on n vertices is ALWAYS connected?

Answer: m = (n - 1)(n - 2) / 2 + 1
Rigorous Derivation:
  1. To find the threshold, we construct the maximum possible edges in a disconnected graph.
  2. A disconnected graph with components of size k and n - k has maximum edges when k = n - 1 and n - k = 1.
  3. This worst-case structure consists of a complete clique Kn-1 and 1 isolated vertex. The total edges in this graph is:
    mmax-disconn = C(n-1, 2) = (n-1)(n-2)/2
  4. Adding just 1 extra edge (+1) forces an edge to connect the isolated vertex, guaranteeing connectivity regardless of edge layout!

SECTION 5

Minimum Edges Required to Guarantee Diameter ≤ d

Question: What is the minimum number of edges \(m\) such that every graph on \(n\) vertices with at least \(m\) edges has diameter \(\le d\), regardless of structure?

The Classical Path‑plus‑Clique Extremal Graph

To keep the diameter large while using many edges, take:

  • A path \(P_{d+1}\) of length \(d\) on \(d+1\) vertices.
  • A clique \(K_{n-d-1}\) on the remaining \(n-d-1\) vertices.
  • Join one endpoint of the path to every vertex of the clique.

The diameter is exactly \(d+1\) — realised by the far endpoint of the path and any clique vertex. Its edge count is

e(G) = C(n − d, 2) + d

Adding one more edge (from the far path endpoint into the clique) shortens the longest shortest path and forces diam(G) ≤ d. Hence the threshold is

m(n, d) = C(n − d, 2) + d + 1

A Richer Extremal Family: Clique Chains

The path‑plus‑clique graph is only one member of a much larger family. Partition the vertex set as

n = n1 + n2 + ⋯ + nd+2, ni ≥ 1

On each block draw a complete graph \(K_{n_i}\), and between consecutive blocks join every vertex of \(K_{n_i}\) to every vertex of \(K_{n_{i+1}}\). No other edges exist. The diameter is exactly \(d+1\), and

e(G) = Σ C(ni, 2) + Σ ni · ni+1

Choosing the \(n_i\) as equal as possible (differing by at most 1) maximises the edge count. Your two‑clique partition \(n_1 = a,\; n_2 = b,\; n_3 = \dots = n_{d+2} = 1\) is a natural special case; the path‑plus‑clique graph is the other extreme \(n_1=\dots=n_{d+1}=1,\; n_{d+2}=n-d-1\).

Clique Chain of Diameter d+1

Consecutive cliques are fully joined (complete bipartite); no other edges exist.
